# Реальные материалы: результат проверки 15 сентября 2026

Проверен 497-страничный учебник дискретной математики. Полная книга дала
758 470 символов текста (781 880 с перекрытиями), превысив лимит 500 000.
Полный агентный прогон выполнен на главах 1–2: PDF 18–44, 52 фрагмента.

**Результат — черновик, не опубликованный курс.** Сгенерированы 3 модуля,
6 уроков, 7 вопросов, 6 практик, 6 кейсов и 12 рубрик. Все уроки рассмотрены QA,
который запросил исправления; повторное извлечение знаний остановлено бюджетом.
В частности, в урок попало строгое включение пустого множества без необходимого
условия непустоты второго множества. У самого QA обнаружены ложные срабатывания.

## Исправления, вызванные этим прогоном

- Известные цитаты и ссылки на знания в карте компетенций дополняют служебные
  списки в коде. Неизвестные идентификаторы остаются ошибкой; связи проверяются
  до запуска следующих агентов.
- Исключение SDK при обрезанном JSON сохраняет доступный usage и допускает
  ограниченный повтор. Локальный отказ по контексту происходит до резервирования.
- Большие пакеты QA и заданий делятся до одного урока. Источники частичного
  модуля ограничены оставшимися уроками и целями.
- В опубликованном представлении графа скрываются объявленные внутренние
  маркеры цитат; метаданные источников сохраняются.
- Память чата обновляется накопительно. Реальный диалог сохранил пример и
  явное сообщение об уровне ученика после двух последовательных свёрток.
- Обратная связь писателю ограничена его уроком; сложные структурированные
  этапы используют отдельный резервный выбор модели.

Проверки: **211 backend-тестов**, 8 прежних предупреждений. Проверены также
интерактивные ответы и навигация автономного HTML-черновика.

## Воспроизведение

Из корня `ciBack`, при установленном Tesseract с `rus` и `eng`:

```bash
AI_MODEL_REASONING=openai/gpt-5.4 AI_REQUEST_TIMEOUT_SECONDS=150 \
.venv/bin/python scripts/evaluate_materials.py \
  --pdf /path/to/material.pdf --pages 18-44 \
  --output-dir /path/to/new-evaluation \
  --credentials /path/to/creeds \
  --title 'Основы теории множеств' \
  --goal 'Задание множеств, включение, операции, мощности и доказательства' \
  --lessons 6 --max-tokens 800000
```

Скрипт создаёт отдельную SQLite БД и checkpoint-файл в каталоге результатов;
производственная БД не используется. Повтор с теми же входами продолжает запуск,
сохраняя общий бюджет. Можно опустить `--credentials`: ключ будет взят из `.env`.
Блокирующая ошибка не отменяет сохранение структурно полного кандидата в
`course-candidate.json`, если такой кандидат уже существует.

```bash
.venv/bin/python scripts/export_evaluation.py /path/to/evaluation \
  --report course-candidate.json --pdf-link ../material.pdf
.venv/bin/python scripts/evaluate_chat_memory.py \
  --directory /path/to/evaluation --credentials /path/to/creeds
```

Экспорт не снимает блокировку QA и не публикует курс. Проверка чата намеренно
устанавливает порог истории в 2 сообщения, чтобы вызвать две свёртки.

## Что не решено

Математические PDF требуют сохранения графических обозначений и проверки
ошибок самого источника. Блокирующие замечания QA нуждаются в независимом
подтверждении: в этом прогоне рецензент оставил `error` у вычисления, которое
сам признал правильным. Перезапуск из ingestion слишком широко затрагивает
зависимые этапы. Целые книги требуют иерархического планирования по главам.

Для этого материала использовались GPT‑5.4‑mini для чтения, уроков и памяти,
GPT‑5.4 для карты, плана и заданий, Sonnet 4.6 для QA. Это результат одного
файла с изменениями кода между запусками, а не доказательство универсально
оптимального выбора моделей. Стандартная reasoning-модель не менялась;
профиль учебника включался переменной окружения.

Локальные результаты сохранены в `../результаты/дискретная-математика/`:
`КУРС.html`, `КУРС.md`, `ОТЧЁТ.md`, `ИСТОЧНИК.md`, JSON-артефакты,
журналы, изображения страниц, отдельная БД и checkpoints. Они не добавлены
в репозиторий вместе с материалом пользователя.

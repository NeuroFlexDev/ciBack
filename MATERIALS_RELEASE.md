# Материалы и AI: контракт доработки

## Интерфейс

- `GET /api/materials/capabilities`: реальные форматы и пределы установки. PDF, DOCX, TXT и MD; PPTX не заявляется.
- `POST /api/courses/{id}/generation-preflight`: тело как у запуска (`settings`, `document_ids`); проверяет число пакетов, минимальное число вызовов и резерв выходных токенов. Не расходует AI и не создаёт запуск.
- `POST /api/courses/{id}/generation-runs`: дополнительный `request_id` сохраняется в БД. Повтор с теми же параметрами возвращает исходный запуск; изменённые параметры с тем же ключом дают 409.
- `settings.approved_plan`: подтверждённый автором упорядоченный список названий уроков, ровно `lesson_count`. Архитектор обязан сохранить его; несовпадение отклоняется валидатором.
- `POST /api/generation-runs/{id}/cancel`: останавливает очередь или дальнейшие этапы после текущего запроса провайдеру. Повтор продолжает тот же checkpoint и журнал расхода.
- `DELETE /api/documents/{id}`: архивирует источник и исключает из поиска/кеша. Исторический файл сохраняется для версий, поэтому по-прежнему учитывается в дисковой квоте.
- `GET /api/courses/{id}/sources/{chunk_id}`: доступный текущий фрагмент источника, его версия, страница и имя файла.
- В списке документов есть `extracted_characters` и `chunk_count`; число символов включает перекрытие поисковых фрагментов.

## Иллюстрации

`POST /api/courses/{id}/images` принимает multipart `file` PNG/JPEG. Файл декодируется и перекодируется без EXIF/вложенного содержимого, проверяются байты и пиксели. SVG не принимается.

`POST /api/courses/{id}/images/generate` принимает `{prompt, request_id}`. Реальная генерация выполняется RQ worker через настроенный OpenAI-compatible Images API. В ответе `queued`, далее `generating`, `pending_review` либо `failed`; состояние читается через `GET /api/images/{id}`. Автоматического повторного платного вызова после неизвестного результата нет.

`POST /api/images/{id}/review` принимает `{decision: "approved"|"rejected", comment}`. Проверенная версия неизменяема. Публикация блокируется, если защищённая иллюстрация не утверждена или относится к другому курсу.

`GET /api/images/{id}/content` требует действующий Bearer. В UI используется запрос с авторизацией и временный blob URL. В текст урока сохраняется стабильный `/api/images/{id}/content`; ученик получает доступ только через назначенный опубликованный снимок.

## Ученический помощник

`GET/POST/DELETE /api/learning/assignments/{id}/assistant/messages` проверяет назначение и его неизменяемую версию. POST: `{lesson_id, question, request_id}`. Ответ содержит `status`, `answer`, `citations`, `error_code`. Помощник получает только опубликованный текст выбранного урока, без ключей ответов. Ссылки на несуществующие уроки отклоняются. Ошибка помощника не изменяет ответы, прогресс или оценки.

История изолирована по пользователю, назначению и версии; удаление убирает содержание, сохраняя обезличенный по содержанию журнал квот. Ежедневный job: `python -m scripts.purge_ai_history`. Период задаётся `AI_CHAT_RETENTION_DAYS`.

## Квоты и локальная поставка

`GET/PUT /api/admin/organizations/{id}/material-policy` доступен только оператору: `disk_bytes_limit`, `image_monthly_limit`, `chat_monthly_limit`. Дисковый лимит учитывает версии документов, изображения и зарезервированное место генерации. Интерактивные вызовы chat/memory/canvas учитываются отдельно в `scoped_ai_usage` с владельцем и состоянием измерения токенов.

`AI_PROVIDERS` задаёт отдельные endpoints; `EMBEDDING_PROVIDER` и `IMAGE_PROVIDER` выбирают независимые сервисы. `AI_LOCAL_ONLY=true` исключает удалённые endpoints и внешние legacy engines; локальные веса embeddings должны быть доставлены заранее. OCR использует локальные Tesseract rus+eng. OCR и нативный разбор выполняются в отдельном процессе с принудительным пределом времени; исходные байты и размер распакованного DOCX ограничены до разбора.

Фактические GPU-пределы, качество на предметных материалах, лицензии локальных весов и работа конкретного Images provider требуют отдельной проверки на целевой установке. Наличие API и автоматических тестов не заменяет эту приёмку.

# Маршрутизация, локальный режим и прогноз токенов

## Что работает

Перед **каждым текстовым AI-вызовом**, включая первую попытку, выбирается
разрешённая пара «провайдер + модель». Это действует для агентов курса, чата,
сжатия памяти и действий канвы. Режим по умолчанию — `adaptive`.
Изменения требуют обновления backend и frontend, применения миграций и
перезапуска backend и worker; сами по себе файлы в репозитории не меняют прод.

Порядок работы:

1. Для агента курса проверить сохранённый результат и кеш владельца курса.
2. Проверить ограничения входа, вызовов и токенов. Прогноз не ослабляет лимиты.
3. Отобрать настроенные провайдеры и одобренные для роли модели: доступность,
   размер контекста, JSON, отдельный проверяющий для критика.
4. Оценить входные и выходные токены, затем стоимость каждого подходящего маршрута.
5. Выполнить выбранный вызов; сохранить фактический расход и результат проверки.
6. При транспортном сбое исключить недоступного провайдера на время и выбрать
   следующий маршрут. При исчерпании допустимых попыток перейти в локальный режим.

Если настроен только VSELLM и каталог пуст, маршрутизатор сравнивает только
основную модель. Дополнительные провайдеры не появляются без endpoint, ключа и
разрешённых моделей. Реальные калибровочные запуски сделаны через VSELLM;
переключение между разными endpoint проверено автоматическими тестами.

## Размер контекста

`AI_MAX_INPUT_TOKENS=0` (по умолчанию) отключает общий потолок входа в 64 000
токенов. Каждый запрос использует доступное окно выбранной модели с резервом
под ответ. Проверяются полный запрос, максимальный ответ и сумма входа с ответом.
Ограничения маршрутов из `AI_ROUTING_CANDIDATES` продолжают действовать.
Для модели вне встроенного каталога задайте её реальные ограничения в этом списке.
Положительное значение `AI_MAX_INPUT_TOKENS` включает дополнительный лимит установки.

При обновлении существующего сервера замените `AI_MAX_INPUT_TOKENS=64000` на `0`
в его `.env`, если настройка там указана, обновите образ и Compose, затем
пересоздайте backend и фоновые процессы. Старые переменные не меняются от простого
перезапуска процесса. Для профиля `deploy/dev-platform` используйте
`docker compose --env-file .env --env-file .images.env up -d backend worker outbox`
из каталога развёртывания. Значение `0` поддерживается только обновлённым образом;
старые версии требуют положительное число.

Большие наборы фактов по-прежнему делятся на части по окну модели без удаления
записей. Это не отменяет отдельные ограничения расходов, размера источников,
истории чата и длины генерируемого ответа.

## Аварийное поведение

| Действие | Что получает пользователь при недоступности внешнего AI |
|---|---|
| Чат | Ответ настроенной локальной модели, если она подходит; иначе точные выдержки из доступных источников с ссылками. Если совпадений нет — понятное локальное сообщение, сохранённое в истории |
| Канва | Сообщение о доступном ручном редактировании; узлы и связи не меняются |
| Генерация курса | Статус `paused`, сохранённые этапы и кнопка «Продолжить генерацию» |
| Недоступная очередь запуска | Сохранённый запуск со статусом `paused`, HTTP 202 и адрес состояния |
| Недоступные embeddings | Текстовые фрагменты остаются в БД и доступны через поиск по словам; заполнить векторы можно повторной индексацией |

Локальная модель — обычный разрешённый маршрут. При низкой цене она может быть
выбрана и в штатном режиме; для тяжёлых ролей её нужно отдельно проверить и
разрешить. Последний уровень защиты — локальные ответы и поиск, которым модель
вообще не нужна. Полная генерация курса без внешних API возможна только при
наличии подходящих локальных моделей для всех нужных ролей, включая критика.
Модели и их веса этим изменением на сервер не устанавливаются.

Пауза продолжает **тот же run ID** и использует его контрольные точки, артефакты
и журнал расходов. Повторное нажатие не создаёт параллельный активный запуск.
Если очередь RQ уже назначила автоматическую повторную попытку, отображается
ожидание восстановления. После исчерпания автоматических попыток остаётся пауза
с ручным продолжением. Непроверенный курс не объявляется готовым.

Это защита от недоступности AI/очереди, пока работают приложение и БД.
Неверный ввод, отсутствие доступа и нарушения качества остаются отдельными
состояниями. Недоступность самого сервера требует инфраструктурного резервирования.

## Выбор маршрута

Основная оценка стоимости вызова:

`(прогноз входа × цена входа + прогноз выхода × цена выхода) / 1 000 000`.

У агентов курса рейтинг дополнительно учитывает историю прохождения локальных
проверок: стоимость делится на `(9 + успешные проверки) / (10 + учтённые попытки)`.
Это эвристика выбора маршрута, а не надбавка в базовую модель расхода токенов.
История ограничена владельцем, ролью, отпечатком политики и размером входа.
Чат/память/канва используют стоимость и доступность без истории проверок курса.

После 10 проверенных ответов кандидат с долей успеха ниже 85% исключается из
адаптивного выбора. После нарушения контракта следующий динамический кандидат
должен иметь более высокий `tier`; при отсутствии кандидата остаётся основная
или резервная политика. Основной маршрут участвует в сравнении при известной цене.
Наличие `contract_pass` означает прохождение проверок шага, а не приёмку всего курса.

Транспортная ошибка, 429, 5xx, отсутствие средств/прав у провайдера открывают
его временную блокировку на 60 секунд. Она общая для процессов через Redis;
при недоступном Redis работает локальная блокировка процесса. Дополнительно
история трёх последних транспортных сбоев исключает маршрут на 300 секунд.
Скрытые повторы SDK выключены; число попыток ограничено `AI_MAX_ATTEMPTS`.

## Настройка провайдеров

Перед обновлением выполнить `alembic upgrade head`. Миграция `20261019_0017`
добавляет JSON-журнал маршрута, `20261019_0018` — состояние `paused`.
Backend и worker должны получать одинаковые настройки.

```dotenv
AI_ROUTING_MODE=adaptive
AI_PROVIDERS=[]
AI_ROUTING_CANDIDATES=[]
AI_PROVIDER_COOLDOWN_SECONDS=60
AI_TOKEN_FORECAST_PATH=app/ai/data/token_forecast.json
```

Для диагностического сравнения доступны `shadow` (только записывает предложенный
маршрут) и `off` (основная/резервная политика). В штатной конфигурации — `adaptive`.

`AI_PROVIDERS` — JSON-массив. VSELLM уже добавлен из `VSELLM_BASE_URL` и
`VSELLM_API_KEY`. Пример дополнительных endpoint:

```json
[
  {"id":"secondary","base_url":"https://api.example.com/v1","api_key_env":"SECONDARY_API_KEY","timeout_seconds":45},
  {"id":"local","base_url":"http://ollama:11434/v1","local":true,"timeout_seconds":20}
]
```

`api.example.com` — заглушка, её нужно заменить настоящим endpoint.
В JSON хранится имя переменной, ключ передаётся только через окружение процесса.
Для дополнительных имён секретов добавить соответствующий env в Compose.
Для `OPENROUTER_API_KEY` и `DEEPSEEK_API_KEY` передача уже предусмотрена.
Наличие ключа само по себе не включает новую модель. В контейнере `127.0.0.1`
указывает на сам контейнер: для локального AI нужен его доступный сетевой адрес.

Пример элемента `AI_ROUTING_CANDIDATES` с **условными** моделью, ценами и лимитами:

```json
[
  {
    "provider":"secondary", "model":"tested-model-id",
    "roles":["ingestion","chat"], "approved":false, "tier":0,
    "input_rub_per_million":"10", "output_rub_per_million":"40",
    "max_input_tokens":32000, "max_output_tokens":6000, "context_window":64000,
    "json_mode":true
  }
]
```

`approved:true` выставляется после проверки модели на материалах Лерниума.
Цены — рубли за миллион токенов, включая выбранный диапазон длины контекста.
Пара `(provider, model)` должна быть уникальной. Для `critic_qa` нужен флаг
`independent_review:true` и модель, отличная от writer. Для роли `vision` нужен
флаг `vision:true`. Передача специальных параметров API допускается в `extra_body`;
это административная конфигурация, а не пользовательский ввод.

Адаптер использует стандартный OpenAI-совместимый Chat Completions. Возможности
конкретной модели нужно проверить: JSON, лимит выхода и дополнительные поля API
не универсальны. Для нестандартных ответов, reasoning-полей или инструментов
может понадобиться отдельный адаптер. См. [документацию LangChain](https://docs.langchain.com/oss/python/integrations/chat/openai)
и [локальный OpenAI-совместимый API Ollama](https://docs.ollama.com/api/openai-compatibility).

## Эмпирический прогноз расхода

Модель: `app/ai/token_forecast.py`, коэффициенты: `app/ai/data/token_forecast.json`.
Не требует дополнительного AI-запроса, GPU, скачивания токенизатора или ML-сервиса.

Признаки: роль агента, запрошенная модель, размер сформированного промпта в UTF-8,
число уроков/объектов в пакете. Для каждой пары роль/модель:

- вход — наблюдаемое отношение фактических токенов к байтам промпта;
- выход при малом числе примеров — медиана токенов на единицу работы;
- от пяти примеров — небольшая регуляризованная линейная регрессия по размеру
  промпта и объёму работы;
- неизвестная модель — явно помеченная предварительная оценка `uncalibrated_prior`.

В обучение входят только первые успешные попытки с `usage` от провайдера.
Ошибки, повторные попытки, доработки по замечаниям и неизвестный расход исключаются.
Кеш-попадание не создаёт новый оплаченный вызов. В прогноз не добавлены аварийный
резерв, скидки кеша, OCR, embeddings, внешние инструменты и труд команды.

Для нового курса endpoint без AI-вызовов:

```http
POST /api/courses/{course_id}/ai/forecast
Authorization: Bearer …
Content-Type: application/json

{"lesson_count":6,"document_ids":[42,43]}
```

Доступен владельцу курса после обработки документов. Возвращает оценку токенов
и рублей по этапам, число вызовов, диапазоны и признаки предварительности.
До генерации размеры будущих промптов оцениваются по обучающим примерам;
это менее точная задача, чем прогноз по уже сформированному промпту.
Диапазоны эвристические, **не статистические доверительные интервалы**.
Пока настройки тестов/сложности и нелинейный рост больших курсов отдельно не обучены.

Снимок цен VSELLM от 19.10.2026 для основной политики: GPT-5.4 mini — 83/497,
Claude Sonnet 4.6 — 332/1658, Gemini 2.5 Flash — 33/276 ₽ за миллион входных/выходных
токенов соответственно. Источники: [mini](https://vsellm.ru/models/openai/gpt-5.4-mini),
[Sonnet](https://vsellm.ru/models/anthropic/claude-sonnet-4.6),
[Flash](https://vsellm.ru/models/google/gemini-2.5-flash).
Оператор должен обновлять цены; расчёт без скидок не равен счёту провайдера.
Для новых маршрутов цены задаются в каталоге.

## Первые измерения и повторное обучение

[Отчёт TOKEN_FORECAST_CALIBRATION.md](TOKEN_FORECAST_CALIBRATION.md) фиксирует три
изолированных запуска на реальном учебнике: 23 наблюдения, предварительные
коэффициенты и ограничения проверки. Ни один из трёх курсов пока не принят
целиком; это калибровка отдельных этапов, а не доказательство себестоимости
успешного полного курса.

Собрать новый платный запуск в отдельный каталог:

```sh
python scripts/evaluate_materials.py --pdf /path/book.pdf --pages 18-21 \
  --output-dir /path/evaluation/course-01 --credentials /secure/key-file \
  --title 'Тема курса' --goal 'Учебная цель' --lessons 2 --max-rubles 150
```

Лимит в этом скрипте — консервативный резерв текстовых вызовов; embeddings/OCR
учитываются отдельно. Резерв сохраняется между перезапусками. Один каталог
нельзя одновременно использовать из нескольких процессов. В каталоге находятся
исходные материалы и ответы моделей: не публиковать его как открытый датасет.

Обучить без сетевых вызовов:

```sh
python scripts/calibrate_token_forecast.py \
  --reports /path/course-01/report.json /path/course-02/report.json \
  --output app/ai/data/token_forecast.json \
  --observations-output /path/token-observations.jsonl \
  --validation-output /path/validation.json
```

Валидация исключает целый курс из обучения, затем проверяет его вызовы. Веса
содержат только агрегаты, без ключей, промптов и цитат. Пересобирать после изменения
промптов, моделей или схемы пакетов. Для следующей проверки нужен разнообразный
набор источников и завершённые курсы; текущие три темы одного учебника этого
не заменяют. До такой проверки `provisional` остаётся включённым.

## Наблюдаемость и оставшиеся границы

`GET /api/generation-runs/{id}/usage` показывает разрешённому владельцу вызовы,
модель, провайдера, решение маршрутизатора, прогноз и фактический `usage`.
Неотправленные вызовы имеют статус `unavailable` и нулевой резерв. Если запрос
отправлен, но расход неизвестен, остаётся консервативный резерв.
В JSON маршрута не сохраняются ключи, тексты документов или промпты.

Пока не реализованы: общий атомарный денежный бюджет организации, распределение
по нагрузке/задержке, ограничения местоположения провайдера, отдельная маршрутизация
embeddings и полная стоимость OCR/инструментов. Цена принятого курса должна
дополнительно учитывать все оплаченные неудачи, когда появятся надёжные данные;
текущий базовый прогноз намеренно их не включает.
